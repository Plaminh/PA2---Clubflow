## 6. CSS

The selected approach is plain CSS with no framework or dependencies. The shared spacing scale is 4, 8, 12, 16, 24, 32, 48, and 64 px. Styles are mobile-first, with explicit breakpoints at 768 px and 1280 px. The responsive implementation pass is not complete.
